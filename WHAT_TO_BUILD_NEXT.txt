1. 📸 PROFILE PHOTOS
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   • Upload form (Vue component)
   • Image cropping (photo gallery)
   • Admin approval queue (new tab in admin)
   • Modesty validation (headshots only)
   • Before/after: sad ☹️ → happy ☺️
   
   Effort: 4-5 days
   Impact: Game-changing

   $ Create Photo model + migration
   $ Add photos table to database

   $ Add photo gallery to profile view


2. 💬 REAL-TIME MESSAGING
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

        but then having no phone to call!
   
   Build:
   • Chat interface (1-on-1)
   • Real-time delivery (WebSocket or polling)
   • Read receipts (shows when message seen)
   • Typing indicators ("User is typing...")
   • Message history
   • Block/report functionality
   
   Effort: 5-7 days
   Impact: Critical engagement driver
   
   Start with:
   $ Create Message model + migration
   $ Create ChatController
   $ Build Vue Chat component
   $ Add WebSocket (or polling) for real-time


3. 🔍 ADVANCED SEARCH
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Why: Members need to find matches. Random browsing only works in movies.
   
   Build:
   • Age range filter
   • Location filter
   • Education level filter
   • Practice level filter (religious)
   • Family goals filter
   • Appearance preferences
   • Save search filters
   • Smart suggestions
   
   Effort: 3-4 days
   Impact: High engagement, discovery
   
   Start with:
   $ Create filter UI component
   $ Build complex Eloquent queries
   $ Add filter persistence (URL/session)
   $ Cache popular filter combinations


4. 💝 IMPROVED PROPOSALS
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Why: Proposals are core to matrimony. Make them beautiful + intuitive.
   
   Build (improvements to existing ProposalController):
   • Add custom message field
   • Status tracking (sent → viewed → responded)
   • Accept / Decline / Maybe buttons
   • Timeline view (when was it sent, when viewed, etc.)
   • Expiration dates (expires after 30 days)
   • Counter-proposals
   • Imam facilitation option
   
   Effort: 3-4 days
   Impact: Core feature polish
   
   Start with:
   $ Add fields to proposals table (message, viewed_at, expires_at)
   $ Improve ProposalController logic
   $ Build proposal modal UI
   $ Add timeline/status view


5. 🔔 NOTIFICATION SYSTEM
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Why: Members check app when notified. No notifications = forgotten app.
   
   Build:
   • In-app notifications (bell dropdown)
   • Email notifications (daily digest)
   • Push notifications (mobile)
   • Notification history page
   • User preferences (which to receive)
   
   Events that trigger notifications:
   ✓ New proposal received
   ✓ Proposal response
   ✓ New message
   ✓ Profile viewed
   ✓ Profile approved
   ✓ Match suggestion
   
   Effort: 3-4 days
   Impact: Engagement + retention
   
   Start with:
   $ Create Notification model
   $ Add notification dropdown to navbar
   $ Build notification preferences page
   $ Create Laravel events (ProposalCreated, MessageSent, etc.)
