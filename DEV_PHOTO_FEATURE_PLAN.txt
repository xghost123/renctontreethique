TECHNICAL SPECIFICATIONS:

DATABASE SCHEMA:
────────────────
photos table:
  - id (bigint, PK)
  - user_id (bigint, FK → users)
  - biodata_id (bigint, FK → biodatas)
  - path (string) - file path in storage
  - original_filename (string)
  - size (bigint) - in bytes
  - mime_type (string) - image/jpeg, etc
  - approved (boolean) - admin approval status
  - approved_by (bigint, FK → users, nullable) - which admin approved
  - approved_at (timestamp, nullable)
  - display_order (integer) - for sorting gallery
  - created_at (timestamp)
  - updated_at (timestamp)


IMAGE REQUIREMENTS:
──────────────────
File Types:   JPG, PNG, WebP
Max Size:     5MB per image
Min Size:     300x300px
Max Images:   5 per profile
Resolution:   Optimize to 1200x1200px
Format:       Store as JPEG (quality 85%) for optimization


STORAGE:
────────
Path: storage/app/public/photos/{user_id}/{photo_id}.jpg
Public URL: /storage/photos/{user_id}/{photo_id}.jpg
Symlink: php artisan storage:link (already done if exists)


API ENDPOINTS:
──────────────
POST /api/photos/upload
  Body:
    - photo (file)
    - biodata_id (integer)
  Response:
    {
      "id": 1,
      "path": "/storage/photos/1/photo_123.jpg",
      "approved": false,
      "size": 245682,
      "message": "Photo uploaded successfully"
    }

DELETE /api/photos/{id}
  Response:
    { "message": "Photo deleted" }

GET /api/biodata/{id}/photos
  Response:
    [
      {
        "id": 1,
        "path": "/storage/photos/1/photo_123.jpg",
        "approved": true,
        "approved_at": "2026-08-04T10:00:00Z"
      }
    ]

POST /api/admin/photos/approve
  Body:
    - photo_id (integer)
    - approved (boolean)
  Response:
    { "message": "Photo approval updated" }

SECURITY CONSIDERATIONS:

✓ File validation (type + size)
✓ User can only delete own photos
✓ Only admin can approve photos
✓ Prevent directory traversal
✓ Scan for malware/exploits
✓ Rate limiting on uploads
✓ Quota per user (5 photos max)


ERROR HANDLING:

- File too large → "Image must be under 5MB"
- Invalid format → "Only JPG, PNG, WebP allowed"
- Upload failed → Retry mechanism
- Database error → Graceful fallback
- Storage error → Clear error message
