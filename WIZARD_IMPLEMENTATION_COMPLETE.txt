ARCHITECTURE & DESIGN
════════════════════════════════════════════════════════════════════════════

Component Hierarchy:
  
  ProfileWizard.vue (Main Container)
    ├─ Progress Bar Component
    ├─ Step Indicators (clickable)
    ├─ Form Content (dynamic)
    │  └─ Current Step Component
    │     ├─ Input Fields
    │     ├─ Validation Messages
    │     └─ Help Text
    ├─ Navigation Buttons
    │  ├─ Previous Button
    │  ├─ Save Status
    │  └─ Next/Finish Button
    └─ Auto-save Indicator

State Management:
  • currentStep (ref) - Current step number (1-8)
  • formData (ref) - Array of 8 step objects
  • validationErrors (ref) - Validation error messages
  • isLoading (ref) - Loading state
  • isSaving (ref) - Auto-save state
  • saveStatus (ref) - Save status message
  • lastSaved (ref) - Last save timestamp

Data Flow:
  1. User fills form in current step
  2. Form emits 'update' event with new data
  3. Parent component receives and stores data
  4. Auto-save triggered (API call to /api/biodata/step/{step})
  5. Save status displayed to user
  6. User clicks Next/Previous
  7. Navigation updates currentStep
  8. New step component mounts and receives saved data
  9. On final step, user clicks Finish
  10. All data sent to /api/biodata/complete endpoint

API ENDPOINTS (Ready to implement)
════════════════════════════════════════════════════════════════════════════

Save Individual Step:
  POST /api/biodata/step/{step}
  Body: { step: number, data: object }
  Response: { success: boolean, message: string }

Save Full Draft:
  POST /api/biodata/save-draft
  Body: { allData: array }
  Response: { success: boolean, draftId: string }

Retrieve Draft:
  GET /api/biodata/draft
  Response: { success: boolean, data: array }

Complete Wizard:
  POST /api/biodata/complete
  Body: { allData: array }
  Response: { success: boolean, biodataId: string, redirectUrl: string }

Get Progress:
  GET /api/biodata/progress
  Response: { completedSteps: array, currentStep: number }
