🔐 BACKEND API ENDPOINTS (for admin):

Route Prefix: /api/admin (requires auth + admin role)

Dashboard:
   GET /api/admin/dashboard
        → Returns dashboard metrics and statistics

Users:
   GET /api/admin/users
        → List all users with pagination/filter
   POST /api/admin/users/role
        → Change user role
   POST /api/admin/users/biodata-status
        → Update user biodata status

Mosques:
   GET /api/admin/mosques
        → List all mosques
   POST /api/admin/mosques/status
        → Update mosque status

Proposals:
   GET /api/admin/proposals
        → View all proposals

Join Requests:
   GET /api/admin/join-requests
        → List mosque join requests
   POST /api/admin/join-requests/decide
        → Accept/reject join request

📝 MODELS & RELATIONSHIPS:

User
   ├─ has many Biodatas
   ├─ has many Proposals
   ├─ has many Likes
   ├─ has many Conversations
   └─ role: enum(member, moderator, admin)

Biodata (User Profiles)
   ├─ belongs to User
   ├─ has many Proposals
   ├─ has many Likes
   ├─ status: pending, approved, trash
   └─ personal, religious, family data

Proposal (Marriage Proposals)
   ├─ belongs to User (proposer)
   ├─ has relationship to Biodata
   └─ status: pending, accepted, rejected

Mosque
   ├─ has many MosqueMemberships
   ├─ has many Users (through memberships)
   └─ status: active, inactive
