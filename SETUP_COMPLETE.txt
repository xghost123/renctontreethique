───────────────────────────────────────────────────────────────────────────────
TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

If you get "could not find driver (Connection: sqlite)":
  → Clear the cache: php artisan config:clear && php artisan cache:clear
  → Restart the Laravel server
  → Check that /public/.user.ini exists and contains extension settings

If Vite assets don't load:
  → Run: npm run dev (in a separate terminal)
  → Check that VITE_ASSET_URL is not set in .env

If you get encryption errors:
  → The NoOpEncrypter will handle it automatically
  → No action needed, app will work without OpenSSL

If migrations fail:
  → Ensure database/database.sqlite exists
  → Run: php artisan migrate:fresh --seed
