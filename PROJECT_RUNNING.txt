API ENDPOINTS (Ready to use)
════════════════════════════════════════════════════════════════════════════

Photos:
  POST /api/photos/upload - Upload new photo
  GET /api/photos/{biodata_id} - List approved photos
  DELETE /api/photos/{id} - Delete photo
  PUT /api/photos/{id}/primary - Set as primary
  GET /api/photos/pending - Admin: List pending
  PUT /api/admin/photos/{id}/approve - Admin: Approve
  PUT /api/admin/photos/{id}/reject - Admin: Reject

Messages:
  POST /api/messages/send - Send message
  GET /api/messages/conversation/{conversationId} - Get messages
  GET /api/messages/poll/{conversationId} - Poll for new messages
  POST /api/messages/mark-read - Mark as read
  DELETE /api/messages/{id} - Delete message

Search:
  GET /api/search - Search with filters
  GET /api/search/recommendations - Get recommendations
  POST /api/saved-searches - Save search
  GET /api/saved-searches - List saved searches

Notifications:
  GET /api/notifications - List notifications
  POST /api/notifications/{id}/mark-read - Mark read
  DELETE /api/notifications/{id} - Delete
  GET /api/notification-preferences - Get preferences
  PUT /api/notification-preferences - Update preferences

Biodata (Profile):
  POST /api/biodata/step/{step} - Save wizard step
  POST /api/biodata/complete - Complete wizard
  GET /api/biodata/{id} - Get profile

TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

If you see "429 Too Many Requests":
  ✅ Already handled - caches cleared, server restarted
  → Rate limiting is working (security feature)
  → Wait 1-2 minutes and try again

If homepage redirects to /admin/login:
  ✅ This is expected behavior
  → Unauthenticated users redirect to login
  → Go to /en or /fr for public homepage
  → Or register at /register first

If styles look wrong:
  ✅ Check if CSS is loading:
     http://127.0.0.1:8000/public/build/manifest.json
  ✅ Clear browser cache (Ctrl+Shift+Delete)
  ✅ Run: npm run build

If API returns 401 Unauthorized:
  ✅ This is expected for protected routes
  → Login first with a test account
  → Use auth token in requests

If database is locked:
  ✅ Run: php artisan migrate:refresh --seed
  ✅ Restart server: Stop process and restart
