**The 5-step Profile Wizard probably collects:**
1. Identity info (age, nationality, etc.)
2. Family info (marital status, children, etc.)
3. Appearance/Physical description
4. Religious practice
5. About me/preferences

**This is actually a GOOD design!**
- Users register quickly (4 steps)
- Users complete profile later (5 steps)
- Lower drop-off rate
- Better UX
